## Description

The meetings folder is the source of truth (L7), so anything can change it — the user in a text editor, an agent writing `meeting.md`, the app itself. The app has to notice and reload.

The trap is already written down in `crates/store/src/lib.rs`: **the watcher must ignore this process's own writes.** The app saves `notes.md` while the user is typing in it. Without suppression the watcher fires, the app reloads the file, and the cursor jumps mid-sentence. The two constants are already there and already have a test pinning their relationship — `SELF_WRITE_SUPPRESSION` at 750 ms must stay longer than `WATCH_DEBOUNCE` at 500 ms.

Agent writes are *not* suppressed. That is the whole point of the watcher.

#### Scope

- Watch the meetings root with `notify`, debounced, and turn changes into UI updates.
- Suppress paths this process just wrote, for the window already defined.
- Handle the folder moving or going missing — TUR-82 lets the user change the meetings directory, so this is reachable in one click.
- A burst of agent writes should be one reload, not a dozen.

#### Gate

- Type a long sentence in the notes pane without the cursor ever moving on its own.
- Write `meeting.md` from an outside process; it shows up in the UI within about two seconds.
- Change the meetings folder in Settings while the app is running; the watcher follows.
