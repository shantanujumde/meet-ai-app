## Description

Raised from TUR-111. The board asked for this to get its own task.

#### What happens

Against the local server on `127.0.0.1:3100`, a request that carries **no** `Authorization` header is handled as the board owner — full company-admin rights. A request that carries a *wrong* token is correctly rejected. So the failure is fail-open on absent credentials, not weak token checking.

#### Evidence (all run 2026-09-28, live server)

| Request | Header | Result |
|---|---|---|
| `GET /api/companies/{id}/members` | none | **200** — full member list, including the owner's user record |
| `GET /api/companies/{id}/members` | `Bearer not-a-real-key` | 401 `Agent token did not verify` |
| `GET /api/agents/me` | none | 401 `Agent authentication required` |
| `PATCH /api/companies/{id}/members/{fake}/permissions` | none | 404 `Member not found` — i.e. it passed authorization and failed only on lookup |

The third row shows the agent-scoped routes do demand a token. It is the **company/board** routes that fall through to an implicit owner identity when nothing is presented.

#### Why it matters

Any process on this laptop — any dependency in any build, any agent, any script — can call board-owner endpoints with a one-line `curl` and no credential. That includes reading the company, editing agents, and changing permissions. There is no audit distinction either: those calls arrive as the owner, so they look like the owner did them.

This is a local-development server, so the blast radius is one machine. It is still worth closing, because agents with shell access run on that machine by design.

#### Suggested shape of a fix

1. Make the board identity require an explicit local credential (a session cookie or a dev token in an env var), rather than defaulting in when the header is missing.
2. If a genuinely unauthenticated local mode is wanted for convenience, gate it behind an opt-in flag that is off by default, and log every call that uses it.
3. Confirm the same default does not exist when the server is bound to anything other than loopback.
