## Description

Tickets are `TICK-NNNN.md` files under a meeting (SPEC §3.3). Phase 4 is where an agent starts writing them; this ticket is the part that has to exist first — somewhere to see them, and a way to make one without an agent involved.

Making one by hand is not a nice-to-have. It is how you find out whether the format is any good before an agent starts producing them in bulk, and it is the fallback when the agent writes something wrong.

#### Scope

- List the tickets attached to a meeting, and show one on its own.
- Create a ticket by hand from the app, with the next `TICK-NNNN` number allocated safely.
- Edit one, written back through `crates/store` (3a) so the file stays the truth.
- Show the "needs attention" state from 3a when an agent has written something the parser could only partly read — with enough on screen to tell what is wrong.

#### Gate

Create a ticket in the app, close the app, open the file in a text editor: it is clean readable markdown that matches §3.3. Edit it there, reopen the app, the change is showing.
