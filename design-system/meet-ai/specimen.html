The Liquid Glass system for meet-ai, a botless meeting assistant for macOS. Glass only works if it survives the backdrop behind it, so this page lets you change that backdrop and switch on the accessibility settings that take the glass away entirely.

Color

Glass surfaces are alpha over an unknown backdrop, so the neutral scale is defined in alpha rather than opaque hex. The opaque values exist only for the Reduce Transparency fallback. Accent and status colors come from the macOS system palette, because system affordances should not use an invented blue.

Rules that decide the look

Never stack glass on glass Two blurs compound into a smear and double the compositing cost. Siblings share one container and become plain fills inside it.
One tinted control per window The tint is what marks the primary action. A second one and it stops meaning anything.
Body text never lives on glass Reading surfaces sit on the opaque content layer. Glass carries labels, icons, and short controls.
Never animate the blur radius It forces a full recomposite every frame, and this app is running Whisper on the GPU at the same time.
Concentric radii are computed An inner radius is the outer radius minus the padding. Write the calc, or corners drift the moment padding changes.
Three glass surfaces at once, maximum Each backdrop-filter is a separate GPU pass. If glass and transcription cannot both fit in the frame budget, glass yields.
Apple ships Liquid Glass as a native API. A web view cannot call it. This system reproduces the observable properties in CSS and takes the real material from the window through Tauri.
